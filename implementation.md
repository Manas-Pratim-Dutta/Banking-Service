# Implementation Plan: NGDRS Bank Service SSO Integration

## 1. Executive Summary & NGDRS Citizen Codebase Findings

Based on our deep dive into the official NGDRS Citizen portal codebase (`ngdrs_citizen-dev`), the Single Sign-On (SSO) integration between the Bank Service and the NGDRS system works as follows:

1. **Target NGDRS Endpoint**: 
   - Route: `POST /asmsso` (mapped to `LoginController@asmsso` in `routes/web/applications.php`).
   - Expected Input Field: `data` (The Base64-encoded, AES-256-CBC encrypted payload string).
   - Target Landing: Once decrypted and authenticated, NGDRS redirects the session to `general-info` with `session('sso_payload')` initialized.

2. **Decryption Logic in NGDRS (`LoginServices::decryptData`)**:
   ```php
   $key = env('APP_CRYPTO_KEY', '1234567890123456');
   $cipher = "AES-256-CBC";
   $iv = "1234567890123456";

   $decrypted = openssl_decrypt($payload, $cipher, $key, 0, $iv);
   $json = json_decode(trim($decrypted), true);
   ```

3. **Expected Payload Schema (`ArrayBuilder.php` & `LoginServices.php`)**:
   NGDRS extracts the payload into user registration and single-window records via `ArrayBuilder::arrCitizenUserRegSave` and `ArrayBuilder::trnSingleWindowData`:
   - `contact_fname`: Authorized Officer First Name (Mandatory for validation)
   - `contact_lname`: Authorized Officer Last Name
   - `mobile_no`: Authorized Officer Mobile Number (Mandatory: used with `contact_fname` to generate NGDRS `user_name`)
   - `email_id`: Authorized Officer Email ID
   - `user_type`: `'B'` (Mandatory: specifies Bank User to filter articles: `[51, 40, 92]` for Mortgage deeds)
   - `bank_user_id`: Officer Identifier (e.g., `AGB-GHY-01`)
   - `bank_trans_id`: Unique UUID generated by Bank Service (saved to `trn_general_info.bank_trans_id`)
   - `process`: `'I'` (Incoming registration flow; lands directly into `general-info`)
   - `building`: Branch address or premises
   - `city`: Branch district / town
   - `pincode`: Pincode
   - `state_id`: `18` (Assam State Code)
   - `pan_no`: Authorized Officer PAN Number (from statutory requirements)
   - `service_id`: `1`
   - `portal_no`: `1`
   - `response_url`: Bank callback URL
   - Additional Mortgage Metadata:
     - `deed_no`: Sequential Deed Identifier (e.g., `AGB/2026/BR001/00001`)
     - `bank_code`: Bank Identifier (e.g., `AGB`, `SBI`, `HDFC`)
     - `bank_name`: Bank Legal Name (e.g., `Assam Gramin Bank`)
     - `branch_code`: Branch Code (e.g., `BR001`)
     - `branch_name`: Branch Name (e.g., `Guwahati Kamrup Branch`)
     - `ifsc_code`: Branch IFSC Code (e.g., `AGB0001102`)
     - `borrower_name`: Mortgagor Name
     - `borrower_mobile`: Mortgagor Mobile
     - `borrower_pan`: Mortgagor PAN
     - `loan_amount`: Sanctioned Loan Amount
     - `stamp_duty`: Calculated Stamp Duty (2%)
     - `property_details`: Land parcel specification (Dag No., Patta No., Mouza)

## 2. SSO Handshake Architecture & Zero-Form Self-Submit Flow

The user requirement states: **"no need of form to show just post self submit kind of it with payload like this"**.

```
+---------------------------------------------------------------------------------------------+
|                                    Bank Service Microservice                                |
+---------------------------------------------------------------------------------------------+
|  Branch Authorized Officer clicks "Proceed to NGDRS SSO Registration"                       |
|                                     |                                                       |
|                                     v                                                       |
|  [ DeedRegistrationController@initiateSso ]                                                 |
|  1. Extract Context: Authenticated Officer, Branch, Bank, Deed                              |
|  2. Construct ArrayBuilder-compliant JSON payload                                           |
|  3. Encrypt via AES-256-CBC: openssl_encrypt($json, 'AES-256-CBC', $key, 0, $iv)           |
|  4. Log attempt in PostgreSQL `sso_audit_logs`                                              |
|  5. Return Clean Self-Submitting Auto-POST Document (Zero User Input Required)              |
+---------------------------------------------------------------------------------------------+
                                      |
                                      | HTTP POST (field: "data")
                                      v
+---------------------------------------------------------------------------------------------+
|                    State NGDRS Portal (ngdrs_citizen-dev /asmsso)                           |
+---------------------------------------------------------------------------------------------+
|  1. LoginController@asmsso receives `request('data')`                                       |
|  2. LoginServices::decryptData($enctyptedData) -> validates contact_fname, mobile_no        |
|  3. ArrayBuilder::arrCitizenUserRegSave creates/updates user with user_type = 'B'           |
|  4. ArrayBuilder::trnSingleWindowData logs single window transaction                        |
|  5. Session initializes `sso_payload.bank_trans_id` and `user_type = 'B'`                   |
|  6. Redirects directly to `general-info` with mortgage article pre-selected [51, 40, 92]    |
+---------------------------------------------------------------------------------------------+
```

## 3. Detailed Component Plan

### A. Dynamic ArrayBuilder Payload Formatter (`app/Services/NgdrsPayloadBuilder.php`)
Create a dedicated formatter matching `ArrayBuilder.php` in `ngdrs_citizen-dev`:
```php
public static function build(Deed $deed, BranchUser $officer, Branch $branch, BankMasterUser $bank): array
{
    // Split officer name into first and last name
    $nameParts = explode(' ', trim($officer->name), 2);
    $fname = $nameParts[0];
    $lname = $nameParts[1] ?? 'Officer';

    return [
        // Fields strictly required by ArrayBuilder::arrCitizenUserRegSave & trnSingleWindowData
        'contact_fname'   => $fname,
        'contact_mname'   => null,
        'contact_lname'   => $lname,
        'building'        => $branch->address ?? $officer->address,
        'street'          => $branch->address,
        'city'            => $branch->district,
        'pincode'         => '781005',
        'state_id'        => 18, // Assam
        'email_id'        => $officer->email,
        'mobile_no'       => preg_replace('/[^0-9]/', '', $officer->mobile_number),
        'user_type'       => 'B', // Bank User Type
        'bank_user_id'    => $officer->officer_id,
        'rtps_trans_id'   => $deed->bank_trans_id,
        'bank_trans_id'   => $deed->bank_trans_id,
        'process'         => 'I', // Ingestion flow to general-info
        'service_id'      => 1,
        'portal_no'       => 1,
        'pan_no'          => $officer->pan_number,
        'response_url'    => route('deeds.show', $deed->id),

        // Deed & Mortgage metadata consumed by GeneralInfoService & Land Records
        'deed_no'          => $deed->deed_no,
        'bank_code'        => $bank->bank_code,
        'bank_name'        => $bank->bank_name,
        'branch_code'      => $branch->branch_code,
        'branch_name'      => $branch->branch_name,
        'ifsc_code'        => $branch->ifsc_code,
        'district'         => $branch->district,
        'borrower_name'    => $deed->borrower_name,
        'borrower_mobile'  => $deed->borrower_mobile,
        'borrower_pan'     => $deed->borrower_pan,
        'property_details' => $deed->property_details,
        'loan_amount'      => (float) $deed->loan_amount,
        'stamp_duty'       => (float) $deed->stamp_duty,
        'timestamp'        => now()->toIso8601String(),
    ];
}
```

### B. Updated `NgdrsSsoService.php`
- Aligns encryption cipher with `ngdrs_citizen-dev`:
  - Cipher: `AES-256-CBC`
  - Key: `config('services.ngdrs.sso_key')` (matching `APP_CRYPTO_KEY`)
  - IV: `1234567890123456`
  - Output: Direct standard Base64 string produced by `openssl_encrypt($json, 'AES-256-CBC', $key, 0, $iv)`.

### C. Zero-Form Instant Self-Submitting View (`sso_redirect.blade.php`)
- No visible form fields to fill.
- Renders an ultra-clean instant redirect container with a progress spinner and auto-executing script:
  ```html
  <form id="ssoRedirectForm" method="POST" action="{{ $ssoEndpoint }}">
      <input type="hidden" name="data" value="{{ $encryptedData }}">
  </form>
  <script>
      document.getElementById('ssoRedirectForm').submit();
  </script>
  ```
- Submits parameter named **`data`** as required by `LoginController@asmsso`.

### D. Sync Mock NGDRS Endpoint (`/mock-ngdrs/portal` & `/asmsso`)
- Add support for `POST /asmsso` to Bank Service mock routes so local end-to-end testing accurately reproduces the exact Citizen route.
